# Cloud Shelf

A beautifully simple frontend for your files.

Cloud Shelf explores a content-first interface for personal libraries stored in Files-compatible storage such as iCloud Drive.

## Prototype goals

- High functionality, low apparent complexity.
- One primary purpose per screen.
- Content first; controls stay quiet until needed.
- Familiar iOS/iPadOS interaction patterns.
- A shared visual language across books, music, games, video, and files.
- Start as a Safari/PWA prototype, then move proven UX into SwiftUI.

## Initial stack

- Vite
- TypeScript
- CSS
- GitHub Pages

The first milestone is a polished, static library shell for iPad Safari.
